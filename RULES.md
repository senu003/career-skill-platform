Project rules
- Work on ONE feature per task. Never touch other stages unless I approve.
- Before changing code: read it and write an audit. No edits during the audit.
- Before refactoring: add characterization tests that capture current behavior.
- Every change must keep the eval harness green or explain the metric change.
- Never remove the deterministic safety layer. Log every override.
- Show a plan and wait for my approval before implementing.
- Finish with: files changed, tests run, metrics before/after, known limits.
